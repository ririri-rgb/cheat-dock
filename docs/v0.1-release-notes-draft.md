# Cheat Dock v0.1.0 release notes — draft

> Draft only. Do not publish until the separate release authorization phase.

Cheat Dock v0.1.0 is the first public release of the macOS-first menu-bar cheat sheet utility.

## Highlights

- Universal macOS build for Apple Silicon (`arm64`) and Intel (`x86_64`).
- Fast local search across built-in and personal cheat sheets.
- File-backed Markdown for user-authored Sheets, items, and built-in overlays.
- Custom Sheets and personal items with stable IDs and conservative persistence/migration behavior.
- Shortcut and Command item types, including single-chord Shortcut Record.
- Foreground-app-aware sheet selection without Accessibility permission.
- Local-only design: no account, cloud sync, AI/LLM API, analytics, telemetry, ads, or remote marketplace.
- Commands are reference/copy-only; Cheat Dock does not execute them.

## macOS installation and security note

v0.1 is distributed directly through the official `ririri-rgb/cheat-dock` GitHub Release.

The v0.1 app is **ad-hoc signed, not Developer ID signed, and not Apple-notarized**. macOS may therefore block the first launch of a browser-downloaded copy.

Before choosing macOS's per-app **Open Anyway** / **このまま開く** option, confirm that you downloaded from the official repository and that the Release, filename, and published DMG SHA-256 match what you expect. See the README installation section for the current macOS steps.

SHA-256 is an artifact-integrity check; it does not replace Apple Developer ID identity verification or notarization.

## Known limitations

- Not Developer ID signed or Apple-notarized; first-launch Gatekeeper friction is expected.
- No auto-updater.
- Shortcut Record supports a single chord, not multi-chord sequences.
- GUI creation/editing focuses on Shortcut and Command items; operation/procedure/snippet remain Markdown-compatible and can be edited directly.
- User Markdown reload is popup-open/manual rather than real-time file watching.
- Concurrent GUI/external Markdown conflicts require an explicit reload; there is no three-way merge.
- Built-in starter content is intentionally compact and may expand in later releases.

## Data retention

User-authored Markdown lives under Cheat Dock's identifier-scoped Application Support data. Replacing or deleting only the `.app` bundle is not intended to remove this authored data. Use **Open Data Folder** to inspect the application-owned location before any explicit data removal.
