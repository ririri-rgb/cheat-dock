## Connect

### Connect to a host
- id: connect-host
- title-ja: ホストへ接続
- kind: command
- command: ssh user@host
- aliases: login, remote host, 接続
- tags: connection, remote
- source: https://man.openbsd.org/ssh.1
Starts an SSH client connection to a remote host using the given user name.
