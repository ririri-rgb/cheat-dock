## Basic

### Copy selection
- id: copy-selection
- kind: shortcut
- shortcut: ⌘C
- aliases: copy, コピー
- tags: clipboard, basic
- source: https://support.microsoft.com/en-us/Accessibility/excel/keyboard-shortcuts-in-excel
Copies the current selection to the clipboard.

### Save workbook
- id: save-workbook
- kind: shortcut
- shortcut: ⌘S
- aliases: save, 保存
- tags: file, basic
- source: https://support.microsoft.com/en-us/Accessibility/excel/keyboard-shortcuts-in-excel
Saves the current workbook.
