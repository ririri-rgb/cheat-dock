## Working tree

### Status
- id: status
- kind: command
- command: git status
- aliases: changes, state, 状態
- tags: inspect, working-tree
- source: https://git-scm.com/docs/git-status
Shows paths that differ between HEAD, the index, and the working tree, including untracked files.
