## Navigation

### Go to Folder
- id: go-to-folder
- title-ja: フォルダへ移動
- kind: shortcut
- shortcut: Shift + Command + G
- aliases: path, folder, フォルダへ移動
- tags: navigation
- source: https://support.apple.com/en-us/102650
Opens the Go to Folder dialog in Finder.

### New Finder window
- id: new-window
- title-ja: 新しいFinderウインドウ
- kind: shortcut
- shortcut: Command + N
- aliases: new window, finder window, 新規ウインドウ
- tags: navigation, window
- source: https://support.apple.com/en-us/102650
Opens a new Finder window.

### Open selected item
- id: open-item
- title-ja: 選択項目を開く
- kind: shortcut
- shortcut: Command + O
- aliases: open, launch, 開く
- tags: navigation, files
- source: https://support.apple.com/en-us/102650
Opens the selected file, folder, or application.

## Files

### New folder
- id: new-folder
- title-ja: 新しいフォルダ

- shortcut: Shift + Command + N
- aliases: create folder, new directory, フォルダ作成
- tags: files, create
- source: https://support.apple.com/en-us/102650

### Get Info
- id: get-info
- title-ja: 情報を見る

- aliases: file info, properties, 情報
- tags: inspect, files
- source: https://support.apple.com/en-us/102650

### Quick Look
